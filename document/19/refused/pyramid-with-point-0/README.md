**Stated in:** [generators/com.simplediagrams.pyramid/README.md](../../generators/com.simplediagrams.pyramid/README.md#the-record), The record.

**Caught by the JSON Schemas:** No.

## In this folder

`pyramid-with-point-0.simplediagram/` is a complete document that breaks only this rule. It is stored without the empty `assets/` folder every document needs, because Git does not keep empty folders. Create an empty `assets/` folder inside it before opening it, or the document is refused for that instead.
